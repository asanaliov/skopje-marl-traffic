# Original SUMO OSM Web Wizard export

This directory preserves the original, unmodified files generated by the SUMO OSM Web Wizard.
Every file other than this README was copied byte for byte from the wizard output directory `2026-07-18-15-03-48`.

The wizard generated the scenario on 2026-07-18 at approximately 15:04 local time using Eclipse SUMO 1.27.1.
The source OpenStreetMap snapshot reports an `osm_base` timestamp of 2026-07-18T12:56:44Z.

The selected area is the Skopje bounding box from longitude 21.40246803561273 to 21.43656856814447 and latitude 41.98722100868553 to 42.00874146057494.
The road network and map shapes are based on OpenStreetMap data.
The passenger vehicle demand was generated synthetically by the wizard and must not be treated as measured Skopje traffic volume.
The export also contains public-transport routes and stops derived from the imported map data.

The organized, runnable copy is stored in the neighboring `network`, `demand`, `config`, `polygons`, and `additional` directories.
The scenario will later be cleaned, reduced, and inspected manually before it is used for multi-agent reinforcement-learning experiments.
